Docker入门

常用命令

镜像

命令名称 命令 可选参数
拉取镜像 docker pull [ID]/[NAME] –plantform=xxx：cpu架构
查询所有镜像 docker images
删除镜像 docker rmi [ID]/[NAME]
从镜像创建并运行容器 docker run [ID]/[NAME]

运行镜像可选参数

  • -d：后台运行
  • -p xx:xx：端口映射，主机端口：容器端口
  • -v xx:xx：挂载卷/主机目录：端口目录
  • -e：环境变量
  • –name xxx：起名
  • -it：控制台进入容器交互
  • –rm：停止时自动删除
  • -restart ：自定义重启策略
    • always：立刻重启
    • unless-stop：除了手动关闭的，其他重启

容器

命令名称 命令 可选参数
查询运行中的容器 docker ps -a：查看所有容器
创建容器 docker create [ID]/[NAME] 参数同run
启动容器 docker start [ID]/[NAME]
停止容器 docker stop [ID]/[NAME]
删除容器 docker rm [ID]/[NAME] -f：强制删除正在运行的容器
查看容器参数 docker inspect [ID]/[NAME]
查看容器日志 docker log [ID]/[NAME] **-f ** ：追踪输出，滚动查看
进入容器执行命令 docker exec [ID]/[NAME] xxxxxx

挂载卷

命令名称 命令 可选参数
创建挂载卷 docker volumn create [ID]/[NAME]
查询挂载卷位置 docker volumn inspect [ID]/[NAME]
查询挂载卷 docker volumn list
删除挂载卷 docker volumn rm [ID]/[NAME]
删除未被任何容器使用的卷 docker prune -a
